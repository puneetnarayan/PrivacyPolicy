KP Default

Uses the CURRENTLY LOADED chart (Chart & Analysis tab). An enhanced, auditable presentation of the app's existing standard KP significator engine — planet-wise significator table, node representation, detailed per-planet chains, planet/cusp signification tables, and the house-wise significator breakdown — introduces no new significator rule.

Four-Step Theory

Uses the CURRENTLY LOADED chart (Chart & Analysis tab). For each planet: Step 1 (the planet itself), Step 2 (its Star Lord), Step 3 (its Sub Lord), Step 4 (the STAR LORD of that Sub Lord — not the planet's ordinary Sub-Sub Lord; these are kept as separate fields). Each step's houses are split into Primary (strong) and Secondary (weak) significations. This is a separate interpretation layer from the Chart & Analysis tab's own KP significator table — results are never mixed between the two.

S.P. Khullar

Uses the CURRENTLY LOADED chart (Chart & Analysis tab). One card per planet: Lords of (Sign/Star/Sub/Sub-Sub Lord, each with its own occupied house), Positional (the planet's own significator houses), and the Star Lord / Sub Lord / Sub-Sub Lord's own significator houses. "(+)" marks a planet whose significator houses include both a supporting and an obstructing house.

K. Bhaskaran

Uses the CURRENTLY LOADED chart (Chart & Analysis tab). Table 1: each planet's Star/Sub/Sub-Sub Lord, shown as "Lord-House (that lord's own significator houses)". Table 2: each planet's own significator houses and which cusp(s) it is the Sub Lord of.

Naadi Significators

Uses the CURRENTLY LOADED chart (Chart & Analysis tab). One card per planet: Planet, Star Lord, Sub Lord, and Sub-Sub Lord, each shown with THEIR OWN significator houses — the planetary linkage chain made visible rather than only a final combined list.
